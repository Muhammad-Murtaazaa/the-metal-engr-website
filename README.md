# Metal Engineering

Official website for **Metal Engineering** — Industrial engineering, custom fabrication, conveyor systems, structural steel, site installation, and maintenance solutions based in Lahore, Pakistan.

## Tech Stack

- **Framework:** React + Vite
- **Styling:** Vanilla CSS (Custom Design System, Fluid Clamp Typography, CSS Grid & Flexbox)
- **Icons:** Lucide React
- **Performance:** Hardware-accelerated transitions, lazy-loaded visual assets, full mobile responsiveness (tested down to 320px).

## Project Setup

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/thehaseebullah/metal-engineering.git

# Navigate to project directory
cd metal-engineering

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

Runs the app in development mode at [http://localhost:5173](http://localhost:5173).

### Production Build

```bash
npm run build
```

Builds the application for production to the `dist` folder.
